# 🩸 Hemobit

### Gestão e Distribuição Inteligente de Hemocomponentes

Projeto desenvolvido para o **Projeto Integrador III — ADS 2026.2**, da **CESAR School**, integrando conhecimentos e práticas das diferentes disciplinas do 3º semestre.

O Hemobit é uma aplicação web para auxiliar na **gestão de hemocomponentes**, permitindo o controle de profissionais, hospitais, estoque e solicitações.

---

## 🎯 Objetivo

Centralizar e facilitar o gerenciamento do fluxo de hemocomponentes, desde o cadastro e controle do estoque até a solicitação e acompanhamento dos pedidos realizados pelos hospitais.

---

## 🛠️ Tecnologias

* **Java 17+**
* **Spring Boot**
* **Spring Data JPA**
* **Banco de dados relacional**
* **HTML / CSS**
* **Thymeleaf**
* **Git / GitHub**
* **Jira**
* **Figma**

> O projeto segue as restrições e boas práticas técnicas definidas para o desenvolvimento das disciplinas envolvidas, incluindo a não utilização de mecanismos de geração automática de código boilerplate, como o **Lombok**.
